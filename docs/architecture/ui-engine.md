# Pragion UI Engine

The 0.0.5 UI engine is an offline design system built from standard HTML, custom Pragion CSS, and focused JavaScript modules.

```text
HTML
  ↓
Pragion CSS tokens and components
  ↓
Pragion JavaScript runtime
  ↓
Pragion UI protocol
  ↓
WebView
```

The public component vocabulary uses `pragion-*` names. Business logic remains outside the browser layer.
