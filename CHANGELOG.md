# Changelog

## 0.0.5

### Added

- Pragion UI design tokens and first-party CSS architecture
- offline HTML/CSS/JavaScript UI gallery
- buttons, cards, forms, tables, navigation, dialogs, bottom sheets, tabs, lists, chart, and dashboard foundations
- light, dark, and system themes
- frontend event and JSON protocol foundations
- explicit Python backend and frontend separation documentation
- `pragion ui gallery` local gallery command

### Limitations

- Android WebView packaging and native APK generation remain future work
- chart rendering and full dialog focus trapping are foundations only

## 0.0.4

### Fixed

- `pragion run` now loads the current project instead of a hard-coded example.
- `pragion run` opens a local desktop preview for the supported UI widgets.
- `pragion build android` is now registered and reports missing Android tooling clearly.
- Generated projects use their requested project name and version.

### Limitations

- Native Android APK generation is not implemented yet.
